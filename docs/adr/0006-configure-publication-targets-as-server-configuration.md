# Configure publication targets as server configuration

A 发布目标 is defined entirely by deployment configuration (`LIYAN_PUBLICATION_TARGETS`, plus the ingest credential in `LIYAN_BLOG_INGEST_TOKEN`) rather than by rows a user or an administrator manages through the product. The MVP gives nobody a way to create, bind, authorize, or enter credentials for a destination, so a database table for targets would only be a copy of configuration with a synchronization problem attached; a user's authorization is expressed as the emails a configured target names. Each 发布任务 still copies the target's identity — platform, site, API base — and the author name the user gave into its immutable snapshot, so retained publication evidence stays complete and independently readable even after configuration changes or the 立言任务 is deleted.
